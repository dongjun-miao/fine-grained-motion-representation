# Release checklist

- [x] Original research directory not edited; before/after metadata and selected hashes checked locally.
- [x] No new training, no official test-placeholder evaluation, no publishing or push.
- [x] Raw videos, clips, labels, per-video predictions/features, weights and participant identities excluded.
- [x] VERIFIED / HISTORICAL BUT UNREPRODUCED / PROPOSED / UNSUPPORTED differentiated.
- [x] Local Delta and detector/consistency negative findings retained.
- [x] Headline metrics recomputed from saved private predictions; public aggregates retain source hashes.
- [x] Synthetic CPU tests are labeled engineering-only; no invented empirical numbers.
- [x] Three figures generated from schema/verified aggregates; source code included.
- [x] Internal links, package allowlist, secret/path patterns and archive integrity checked; results in release_validation.json.
- [ ] Before an actual public push, author reviews publication scope of aggregate results and confirms any institutional obligations. No data redistribution approval is inferred here.
- [ ] Author chooses a license for project-owned code; no blanket license was fabricated.
- [ ] Full independent-data training replication remains unavailable in this public package; obtain authorized assets and original private manifests for that purpose.

Unchecked items are stated release limitations, not a request to begin new experiments. This task stops after ZIP packaging and validation.
